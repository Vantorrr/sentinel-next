Sentinel Edge для Windows 10/11 (64-bit)
Версия 0.2.0

Что это
  Программа на компьютере в той же сети, что регистратор.
  Она читает RTSP локально, ищет людей моделью yolo11n и шлёт на сервер
  только JSON-события и heartbeat. Видео на сервер не передаётся.
  Лица сотрудников не распознаются. Карточки LIVE на сервере от этих
  событий сами не становятся зелёными: счётчик кадров сервера — про
  поток, который открыл сам сервер.

Куда ставить
  Компьютер должен быть включён и видеть регистратор по локальному адресу.
  Подходящий компьютер в салоне этим пакетом не проверяется.

Действия
  1. Скопируйте папку на диск, например C:\SentinelEdge
  2. Рядом с Install.bat создайте config.env из env.example и впишите
     адрес сервера, ключ салона и RTSP. Файл не пересылайте.
     Если config.env уже есть от прошлой установки, он не перезаписывается.
  3. Правый клик по Install.bat → Запуск от имени администратора.
     Windows один раз покажет запрос UAC. Это нужно, чтобы создать
     видимую задачу SentinelEdge в Планировщике заданий: запуск при
     загрузке Windows, без входа пользователя, от имени Local Service.
     Задача не скрыта. Повторный Install не качает зависимости заново,
     если набор версий не менялся.
  4. Status.bat показывает возраст последнего декодированного кадра и
     время последнего ответа сервера на события и heartbeat.
     Строка opened без кадра успехом не является.
  5. Stop.bat останавливает работу. Uninstall.bat снимает задачу.
     config.env, очередь и журналы остаются. Uninstall.bat purge
     удаляет и их.

Права
  Установщик просит администратора только на регистрацию задачи и
  закрытый каталог %ProgramData%\SentinelEdge (SYSTEM, Administrators,
  Local Service). Антивирус и TLS не отключаются. Исключения не добавляются.

Ограничения, которые не обещаем
  Windows 7 и 32-bit не поддерживаются. Полная установка, перезагрузка
  и живой RTSP этим архивом на салоне не проверялись.
  Ориентир по ресурсам, не замер салона: компьютер x64 с 4 ГБ ОЗУ и
  несколькими гигабайтами свободного диска под окружение CPU torch и
  модель yolo11n. Точный расход памяти на Windows здесь не измерялся.
  Доставка событий — at-least-once. Если процесс умер после ответа
  сервера 200 и до записи очереди, то же событие может уйти ещё раз.
  Сервер дубликаты не склеивает. При переполнении очереди (1000) самые
  старые события отбрасываются, счётчик dropped_oldest это показывает.
  Обрыв RTSP и обрыв API обрабатываются повторными попытками в том же
  процессе. Падение процесса поднимает Планировщик (перезапуск после
  ошибки, не чаще раза в минуту).

Журнал
  %ProgramData%\SentinelEdge\logs\edge.log, ротация 1 МБ, 5 файлов.
  Пароли и query-строки вырезаются. Diagnose пишет diagnose.json без
  кадров и без ключа API.
