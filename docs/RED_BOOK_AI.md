# Красная книга Вай Тай → AI Sentinel (под ключ)

## Что включено

1. **Замечания** с главой, кодом (`RB-CH3-…`), действием «что сделать»
2. **Telegram** — форматированные уведомления по замечаниям
3. **Пресет зон** — Вход / Ресепшен / Ожидание-чай в один клик
4. **Скор дня** — `/api/v1/analytics/redbook/remarks` + виджет на Обзоре
5. **LLM** — сводки и чат судят по Красной книге

## Точность (честно)

| Правило | Точность |
|---|---|
| Таймер «Гость ждёт без staff рядом» | **детерминировано** (секунды зоны) |
| Таймер «ресепшен пуст» | **детерминировано** |
| Face ReID staff/new/VIP | зависит от качества камеры/энролла |
| Жест «вай», униформа, цветок | **не заявлено** — нужен отдельный vision |

Итого: по таймерам Красной книги (гл.3/11) — жёсткий контроль без «угадывания».  
100% на позах/форме одежды CV не обещаем.

## Как включить в салоне

1. Добавить камеру ресепшен
2. **Зоны → Пресет «Вай Тай · Красная книга» → Применить**
3. Подправить полигоны под кадр
4. В «Люди» заэнроллить Администратора как `staff`
5. Telegram: `/start <API_KEY>` салона
6. `TELEGRAM_BOT_TOKEN` + `ANTHROPIC_API_KEY` в `.env`

## API

- `GET /zones/presets/redbook`
- `POST /zones/camera/{id}/presets/redbook`
- `GET /analytics/redbook/remarks?start=ISO`
